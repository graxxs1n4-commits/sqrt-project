# Root Calculator — веб-версия

## Запуск

1. Установите Python 3.10+.
2. Откройте терминал в папке проекта.
3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Запустите сервер:

```bash
uvicorn main:app --reload
```

5. Откройте в браузере:

http://127.0.0.1:8000

## Возможности

- корень любой положительной степени;
- два действительных корня для положительного числа при четной степени;
- один действительный корень при нечетной степени;
- корень из нуля;
- комплексные корни;
- большие числа с использованием Decimal и метода Ньютона;
- запрос количества знаков после запятой только когда результат не является целым;
- аналитическая форма;
- понятные сообщения об ошибках;
- русский и английский языки;
- переключение языка без перезапуска сервера;
- адаптивный интерфейс для ПК, планшета и телефона.

Язык сохраняется в браузере через localStorage.
